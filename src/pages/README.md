# Pages
页面模块。

This directory stores route-level React components.
这个目录存放与路由对应的页面级 React 组件。

Keep page files focused on composition, state binding and layout assembly.
页面文件应主要负责组合组件、绑定状态和组织布局。

Tabbar first-level routes should keep matching page directories and starter files, even when the page content is still empty.
tabbar 一级路由需要保留对应的页面目录和初始文件，即使页面内容暂时为空也要能正常跳转。
