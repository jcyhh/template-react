# @jcy/create-template-react
React H5 DApp 模板创建工具。

Create a project in an empty directory.
在空目录中创建项目。

```bash
pnpm dlx @jcy/create-template-react .
```

Or create a new child directory.
也可以创建新的子目录。

```bash
pnpm dlx @jcy/create-template-react my-app
```

Then install dependencies and start the project.
然后安装依赖并启动项目。

```bash
cd my-app
pnpm install
pnpm dev
```
